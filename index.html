RESTful response utility

Every status. Two formats.

Request any valid HTTP status code from 100 through 599. Choose a human-readable HTML response or a machine-readable JSON response, with English and Japanese localization.

Try it

HTML

GET /html/{statuscode}?lang=xx

Localized page with the requested final response status.

JSON

GET /json/{statuscode}?lang=xx

A compact response containing only the status and localized message.

About 1xx: informational responses are interim by definition. When supported, 100, 102, or 103 is emitted first; the endpoint then returns the required final 200 response with details.

Supported languages: en, ja. An unsupported lang value quietly falls back to English.

No authentication. No cookies. Responses are not cached.
