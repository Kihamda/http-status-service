HTTP Status Service

Simple status responses for testing and development

Return the status you need.

Choose any HTTP status code from 100 through 599 and receive it as a small HTML page or a JSON response.

Try a response

API routes

HTML

GET /html/{statuscode}?lang=xx

English status heading with a localized explanation.

JSON

GET /json/{statuscode}?lang=xx

status, English message, and localized description.

Examples and response shape

HTML 502 in Japanese · JSON 418 in French

{"status":404,"message":"Not Found","description":"サーバーは要求されたリソースを見つけられません。クライアントエラーの分類に属し、再試行の前にリクエスト、認証情報、または対象リソースの見直しが必要な場合があります。"}

Languages

en, ja, de, es, fr, ko, pt-BR, and zh-CN are supported.

  • Without lang, the service uses Accept-Language, then English.
  • Unsupported values silently fall back to English.
  • pt maps to pt-BR; zh and zh-Hans map to zh-CN.

HTTP behavior

  • The accepted range is 100–599. Registered reason phrases follow IANA; other values use Unassigned.
  • Descriptions are concise localized summaries based on MDN and the referenced standards.
  • 1xx responses are interim. Where supported, 100, 102, or 103 is emitted first, followed by the required final 200 response.
  • 204, 205, 304, and HEAD requests have no response body.
  • Responses are not cached. No authentication, cookies, or environment variables are used.
